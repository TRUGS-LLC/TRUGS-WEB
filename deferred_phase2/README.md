# Archived Phase 2 scaffold

This directory is an archived, non-importable scaffold for hub federation and
refresh. It is excluded from the release wheel and the configured test suite.

Its tests still import the former `trugs_tools.web` namespace, and the hub
orchestrator references sibling pipeline modules that are absent here. These
files are design history, not runnable modules or supported examples.

The scaffold is retained. Its repair or removal is deferred to T8; no release
version or delivery date is promised by this archive.
